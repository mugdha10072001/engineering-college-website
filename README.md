Technologies used
React, TypeScript, Vite, Tailwind CSS v4 (custom design tokens for colors and fonts), Lucide React icons, Google Fonts (Archivo and Cormorant Garamond), Git and GitHub for version control, and Vercel for hosting.
Features
• Responsive layout for mobile, tablet and desktop
• Sticky header with a dismissible admissions announcement bar
• Dropdown navigation on desktop and an accordion menu on mobile
• Full-width hero section with image overlay and call-to-action buttons
• Pages for About, Academics, Admissions, Campus, Research, Placements, Student Life and Media
• Photo gallery with a responsive grid and category labels
• Reusable components such as Container, Breadcrumb, SectionHeading and GalleryGrid
• Footer with quick links, contact details and social links
• Hover effects, smooth scrolling and accessible focus styles
Initial review process
I planned the pages and the brand palette, set up the project, built a design system in Tailwind, and developed the layout components and then the pages. I ran npm run build and fixed the errors it reported, pushed the code to a public GitHub repository, and deployed it on Vercel. Finally I checked the live site on desktop and mobile.
Deployment steps
1. Run npm run build locally and fix any errors.
2. Create an empty public repository at github.com/new named engineering-college-website.
3. Push the project: git add ., git commit -m "Initial commit", git branch -M main, then git push -u origin main.
4. On vercel.com choose Continue with GitHub, then Add New, Project, and import the repository.
5. Leave the Vite defaults (build command npm run build, output directory dist) and click Deploy.
6. Copy the live URL and paste it into the template above.
